# TraceLink Field Log — Manager Guide

## Manager dashboard

Use this link:

https://dailytasklog.streamlit.app/?view=manager

Bookmark this link for quick access.

## What this dashboard is for

The Manager View is a read-only view of Saniya's internship work log. It is designed to let you quickly review:

- Tasks completed
- Goals for the next day
- Hours logged
- Daily status
- Key learnings
- Ideas / sparks
- Weekly activity
- Manager feedback already posted

Private reflections are not intended to be part of the Manager View.

## How to review an update

### 1. Open the Manager link

Open the manager URL above. The newest week is shown first.

### 2. Review the latest entries

Each day has its own card. Review:

- **Tasks completed** — what was actually worked on/completed
- **Goals for next day** — what Saniya plans to continue or complete
- **Hours** — approximate time logged
- **Status** — On track, Under target, or Blocked
- **Key learning** — useful learning from the day
- **Idea** — optional ideas or observations

### 3. Live updates

The dashboard checks the database every 15 seconds while the page is open.

If Saniya saves a new entry, it should appear automatically in the Manager View during the next refresh cycle.

You do not need to enter Saniya's tasks yourself.

### 4. Leave feedback

At the bottom of each week there is a **Leave a note or suggestion for this week** section.

Enter:

- Your name
- Your comment / suggestion / feedback

Then click **Post note**.

That feedback will appear in Saniya's **Feedback** tab.

### 5. Download the spreadsheet

Open the **Downloads** section near the top of the Manager View.

Click:

**Download full spreadsheet**

The spreadsheet contains:

- Every logged day
- Tasks completed
- Goals for next day
- Hours
- Status
- Notes / blockers
- Key learning
- Ideas
- Reflections
- A separate **Manager Notes** sheet

## What you should not do

- You do not need to edit Saniya's work entries.
- Do not use the intern dashboard for logging on her behalf.
- Use the Manager View's note section for comments or suggestions.

## Recommended routine

A simple workflow is:

**Daily / as needed:** glance at the latest entry.

**Weekly:** review the week's activity, compare tasks against goals, and leave feedback if useful.

**When needed:** download the spreadsheet for a complete record.
