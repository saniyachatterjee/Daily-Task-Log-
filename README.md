# Field Log — TraceLink-styled Streamlit app

## Deploy
1. Push `app.py`, `requirements.txt`, and the `data/` folder to GitHub.
2. Deploy `app.py` on Streamlit Community Cloud.
3. Manager view: append `?view=manager` to the app URL.

## UI update
This version uses a dark TraceLink-inspired enterprise surface with white typography, dark-glass inputs, consistent CTA buttons, and quieter add/remove controls.
